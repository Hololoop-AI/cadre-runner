Story tag-notes · spec review · Round 1 of 3

Tag notes, and filter the list by tag

What this builds

Notes gain optional tags at add time, and notes list gains a --tag filter so a user can see only the notes carrying a given tag. Nothing else about the CLI changes.

Slice 1 — tags travel with a note through storage

notes add "buy milk" --tag errand accepts a repeatable --tag option and persists the tags alongside the note in the existing single JSON storage file. Tag normalization lives in a new module.

Slice 2 — listing filtered by tag

notes list --tag errand prints only the notes carrying errand, in id order. notes list with no --tag is unchanged.

Risks

Slice 1 — the backwards-compatible load is the risky half: a record with no tag field must not become a record with an empty tag list on rewrite.
