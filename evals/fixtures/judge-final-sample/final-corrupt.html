Residual risks

1. Tag case is normalised on write but not on read. normalize_tag() lowercases on add, so --tag Errand stores errand; but notes list --tag Errand compares raw and prints nothing. It is a two-line fix and I did not take it: it is behaviour this story never specified, and it belongs in the follow-up that also settles notes search --tag.

2. Ordering is inherited, not asserted at the boundary. The filtered list is id-ordered because the underlying listing is; nothing in cli.py sorts. If the listing ever changes its order, criterion 2 breaks silently.

1. notes/store.py:96-131 — the writer, and the guard you approved

First because it is the only code in this change that can touch data a user already has. Check: that the if r.tags: guard cannot be bypassed — that no other call site builds the record dict itself.

def _record_to_json(r):
    out = {"id": r.id, "text": r.text}
    if r.tags:
        out["tags"] = sorted(r.tags)
    return out

def save_all(path, records):
    payload = [_record_to_json(r) for r in records]
    tmp = path.with_suffix(".tmp")
    tmp.write_text(json.dumps(payload, indent=2))
    tmp.replace(path)
